# Review Lenses

Use only the lenses relevant to the task.

| Lens | Inspect | Output |
|---|---|---|
| Archaeology | README versus execution | intent/implementation gap |
| Security | credentials, trust boundaries, runtime config | severity and code-only fix |
| Creative systems | story grammar, visual identity, typography, pacing | reusable creative primitives |
| Frontend design | hierarchy, density, responsive behavior, motion | interface critique |
| Agent architecture | roles, tools, handoffs, state, validation | agent graph and contracts |
| Testing | fixtures, assertions, deterministic inputs, CI | confidence and regression plan |
| Publishing | metadata, exports, licenses, provenance | release-readiness report |

Never state that a lens or skill was used unless it was actually available and read. A lens is an analytical frame, not an MCP server.
