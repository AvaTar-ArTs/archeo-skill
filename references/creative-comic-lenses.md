# Creative and Comic Review Lenses

Adapted from the creative skill family in the agent-skills repository.

## Creative ideation

Before implementation, generate several directions under explicit constraints:

- audience and format
- emotional contract
- visual thesis
- production limits
- forbidden generic choices

Choose a direction only after comparing distinct alternatives.

## Comic analysis

For comic, manga, graphic novel, or webtoon work, inspect:

- page or scroll format
- reading direction
- panel hierarchy
- gutter and reveal timing
- character anchors
- camera and repetition
- lettering role
- color or monochrome state
- motif recurrence
- storyboard-to-render data loss

## Structured asset pipeline

Every creative unit should carry:

- stable unit ID
- semantic purpose
- source brief or beat
- prompt or instruction version
- provider/model
- seed when available
- input references
- output path or URI
- postprocess operations
- validation status
- human review notes

## Taste and interface

Ask:

- Does the system have a point of view?
- Is the UI expressing the work's character or merely exposing controls?
- Are typography, color, texture, motion, and hierarchy intentional?
- Does the output look interchangeable with generic AI tooling?
- Which constraints create identity rather than decoration?

## Archeology application

When auditing a creative repository, separate:

1. narrative intent
2. visual grammar
3. generation mechanics
4. composition mechanics
5. publication mechanics
6. asset provenance
7. creator experience

This prevents a prompt preset from being mistaken for a complete creative system.
