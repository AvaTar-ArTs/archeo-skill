# Agent-Skills Integration Map

Source repository: https://github.com/AvaTar-ArTs/agent-skills

This map records selected resources that extend Repository Archaeology. It is an adaptation map, not a wholesale copy of the source tree.

## Process authorities

| Source | Contribution to archeology |
|---|---|
| using-superpowers | Check applicable skills before action; use process skills before implementation skills |
| verification-before-completion | Require fresh evidence before claiming a result |
| workspace-ecosystem-audit | Inventory first, slice data, read purpose, identify risks, refresh after changes |
| workflow-bootstrap | Establish repository workflow and dependencies before execution |
| writing-skills | Treat instructions as executable contracts and validate skill packaging |

## Selection rule

Use only the smallest set of lenses that covers the task. Record which lenses were actually applied in the report. A source path is evidence of availability, not evidence that the source was used.
